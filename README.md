# TIR Text Inline Reference

ComfyUI 프롬프트의 레퍼런스 호출을 찾아 이미지를 불러오고, **SnapRef** 방식으로 모델에 연결하는 노드 팩입니다. TIL과 같은 Sender/Receiver 흐름을 사용하며 Base 노드는 없습니다.

## 동작 방식과 샘플러

Sender는 프롬프트의 `<ref:이미지이름>` 호출을 `ref_stack`으로 전달하고, 출력 문자열에서는 인식한 호출 문법을 제거합니다. Receiver는 이미지 폴더에서 파일을 찾아 SnapRef 어댑터를 모델에 적용하고 `MODEL`을 출력합니다.

Receiver의 `MODEL`은 일반 **KSampler**에 연결할 수 있습니다. ComfyUI 패치 모델로 확산 모델을 실행하는 고급 샘플러에서도 사용할 수 있습니다. SnapRef의 기본 레퍼런스 적용은 diffusion model 안에서 처리됩니다. 프롬프트에 `g`를 명시하고 값이 `1`이 아니면 추가 ref guidance를 켜며, 이때 Advanced와 같이 레퍼런스를 긍정/부정 조건 양쪽에 적용합니다. 이 기능은 SnapRef의 post-CFG 콜백을 사용하므로 사용자 정의 Guider/샘플러가 해당 콜백을 실행하지 않으면 적용되지 않을 수 있습니다.

## 노드와 입력

- **TIR Ref - Sender**: 호출을 파싱해 `ref_stack`과 호출이 제거된 프롬프트를 출력합니다.
- **TIR Ref - Receiver**: 호출된 이미지를 폴더에서 찾아 선택한 SnapRef 어댑터로 모델을 패치합니다.
- **TIR Ref - Sender (Wireless)** / **TIR Ref - Receiver (Wireless)**: 채널 이름으로 같은 요청을 전달합니다.

Receiver에는 `MODEL`, `VAE`, `CLIP`, `ref_stack`, 이미지 폴더, SnapRef 어댑터, 하위 폴더 검색 설정이 있습니다. SnapRef에 프롬프트 임베딩을 전달하므로 CLIP 입력이 필요합니다. `include_subfolders`를 켜면 지정 폴더 아래의 하위 폴더까지 검색합니다.

## 프롬프트 문법

기본 문법은 다음과 같습니다.

```text
<ref:이미지이름>
```

| 부분 | 뜻 |
|---|---|
| `ref` | 레퍼런스 호출임을 나타내는 고정 키워드 |
| `이미지이름` | Receiver의 폴더에서 찾을 이미지 파일 이름. 확장자는 적어도 되고 생략해도 됩니다. |
| 옵션 | 필요하면 `:키=값` 형식으로 뒤에 추가합니다. |

확장자를 적으면 해당 파일을 찾고, 생략하면 같은 이름(stem)의 후보 중 경로순 첫 파일을 사용합니다. 하위 폴더는 Receiver의 `include_subfolders`가 켜진 경우에 검색합니다. 하위 폴더 안의 파일은 상대 경로와 확장자를 함께 적어 지정할 수 있습니다.

옵션은 필요할 때만 `키=값`으로 추가합니다.

| 키 | 뜻 | 범위 또는 값 | 기본값 |
|---|---|---|---|
| `g` | 추가 레퍼런스 가이던스. 명시하고 `1`이 아니면 활성화하며, 이때 `ref_in_uncond`도 자동으로 활성화됩니다. | 0–15 | `4.5` 값, 미입력 시 꺼짐 |
| `e` | 추가 가이던스 종료 지점 | 0–1 | `1` |
| `c` | 가이던스 보정: `0` = APG, `1` = rescale, `2` = none | 0, 1, 2 | `0` (APG) |
| `mp` | 레퍼런스 이미지 크기(메가픽셀) | 0.25–2 | `1` |
| `m` | SnapRef 모드: `0` = Character & Style, `1` = Character, `2` = Style | 0, 1, 2 | `0` (Character & Style) |
| `w` | 이 호출 이미지의 상대 가중치. `1`은 학습 기본값입니다. | 0–2 | `1` |
| `s` | 레퍼런스 어텐션 강도. `0`은 학습 기본값입니다. | -3–3 | `0` |
| `rc` | 참조 이미지용 캡션. 큰따옴표로 감쌉니다. | 문자열 | `""` (빈 문자열) |
| `ml` | 이미지 배치: `0` = separate, `1` = stitch | 0, 1 | `0` (separate) |
| `f` | 레퍼런스 충실도. 낮추면 부정 조건에도 약한 레퍼런스를 넣어 프롬프트 자유도를 높입니다. | 0–1 | `1` |

기본값은 `m=0`, `w=1`, `s=0`, `e=1`, `c=0`, `mp=1`, `ml=0`, `f=1`, `rc=""`입니다. `g`를 생략하거나 `g=1`로 쓰면 추가 가이던스는 꺼집니다. `e`와 `c`는 추가 가이던스가 켜졌을 때 적용되며, `g`가 켜지면 SnapRef 동작에 따라 `f`는 사용되지 않습니다.

`m=2`는 SnapRef에 추가될 예정인 Style 전용 모드로 연결되도록 미리 준비한 값이며, TIR은 내부 모드 이름 `style`을 전달합니다. 실제 적용에는 `style`을 지원한다고 어댑터 메타데이터에 기록한 어댑터가 필요합니다. 선택한 어댑터가 이를 지원하지 않으면 Receiver가 해당 어댑터의 지원 모드를 표시하며 오류를 냅니다. `m`을 생략하면 기존 기본값인 Character & Style을 사용합니다.

```text
<ref:이미지이름:rc="short red hair: blue=green eyes":g=4.5:e=0.8:c=0:mp=1:m=2:s=0.3:f=1:ml=0:w=1>
```

옵션의 순서는 자유롭게 쓸 수 있습니다. `rc`는 `rc="설명 문장"`처럼 쓰며 큰따옴표 안에서는 `:`와 `=`도 캡션 문자로 처리됩니다. 캡션 안에 큰따옴표나 역슬래시를 넣을 때는 `\"`, `\\`로 이스케이프합니다.

여러 이미지를 쓸 때는 호출을 반복합니다. 첫 호출의 `g`, `e`, `c`, `mp`, `m`, `s`, `rc`, `ml`, `f` 설정이 묶음 전체에 적용되고, 뒤 호출에서는 `w`를 이미지별로 다르게 지정할 수 있습니다. 따라서 `m=2`를 쓸 때는 첫 호출에 지정하고, 모든 참조 이미지가 같은 Style 모드로 처리되도록 합니다.

```text
<ref:이미지1:ml=0:m=0><ref:이미지2:w=0.6>
```

`ml=1`은 여러 이미지를 하나로 stitch합니다. SnapRef와 같이 stitch에서는 개별 `w`가 무시되며, TIR은 이 동작을 로그에 알리고 결합 이미지에 기본 가중치 `1`을 적용합니다. `ml=0`은 각 이미지를 별도 레퍼런스로 처리해 개별 `w`를 적용합니다.

## 이미지 검색 방식

- 확장자를 쓰면 해당 파일을 선택합니다. 하위 폴더 검색 중 이름이 겹치면 경로순 첫 파일을 선택합니다.
- 확장자를 생략하면 동일한 파일 이름(stem)을 가진 이미지 중 경로순 첫 파일을 선택합니다.
- 기본 `ml=0`에서는 여러 이미지를 SnapRef에 각각 독립된 레퍼런스로 전달합니다. `ml=1`에서는 가로로 이어 붙여 하나의 레퍼런스로 전달합니다.

## 의존성과 설치

ComfyUI에 [SnapRef](https://github.com/ArcAnima/SnapRef)가 설치되어 있어야 합니다. 어댑터 선택 목록은 SnapRef 노드가 제공하는 목록을 사용합니다.

`ComfyUI-TIR` 폴더를 ComfyUI의 `custom_nodes` 폴더에 복사하고 ComfyUI를 재시작합니다.
